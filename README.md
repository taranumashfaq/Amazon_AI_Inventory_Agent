# Amazon AI Supply Chain & Inventory Forecast Agent

An intelligent demand forecasting and inventory risk optimization agent built for Amazon third-party sellers.

## 🚀 Overview
Managing inventory effectively is critical for Amazon sellers. This AI agent leverages machine learning to forecast demand trends, helping sellers avoid stock-outs during high-demand periods and prevent unnecessary overstock storage fees.

## 🛠️ Features
- **XGBoost Demand Forecasting:** Predicts demand based on product metrics and regional trends.
- **Interactive Streamlit Dashboard:** User-friendly web interface for inputting seller parameters.
- **Automated Risk Assessment:** Real-time stock-out vs overstock risk warnings.

## 💻 Tech Stack
- **Machine Learning:** XGBoost, Scikit-learn, Pandas, NumPy
- **Frontend / UI:** Streamlit
- **Deployment:** Google Colab, Localtunnel
